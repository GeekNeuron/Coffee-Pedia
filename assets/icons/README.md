# Icons

This app's icon set (`js/icons.js`) combines:

1. **Hand-authored icons already in the original project** (home, book,
   heart, gear, search, coffee mug, timer, calculator, etc.) — written in
   the Feather/Lucide visual language (24×24 grid, 2px stroke). Kept as-is.

2. **27 icons sourced from [Lucide](https://lucide.dev)** — the actively
   maintained, community-run continuation of Feather Icons — to replace
   the emoji (📜🌱🔥⚗️🧭…) that used to stand in for every encyclopedia
   category and recipe group, and to fix one real mismatch (a clock icon
   was being used for the *temperature* guide).

   Source: https://github.com/lucide-icons/lucide (`/icons/*.svg`)
   License: ISC — see `LICENSE` in this folder. Free for any use,
   commercial or personal, with no attribution required (though this
   file exists to give credit anyway).

No icon artwork is copied from any closed-source, trademarked, or
paid icon set.
